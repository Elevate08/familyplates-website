# FamilyPlates website

The static project website for [FamilyPlates](https://github.com/Elevate08/familyplates), published at [familyplates.org](https://familyplates.org).

## Local preview

Serve the repository root with any static HTTP server. For example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

Pushes to `main` deploy automatically through GitHub Pages. The `CNAME` file configures the `familyplates.org` custom domain.
